# Ark Novel 自己的简繁修正表，补 OpenCC 在小说正文里常见的误转。
# 格式同 OpenCC：简体<Tab>繁体（台湾写法）。
# - 两个字以上：词组，优先于 OpenCC 的词组。OpenCC 从左往右取最长的词，所以要修「不是只有」被拆成「是只」，得写「是只有」这样从出错位置开始的更长的词。
# - 单个字：繁体到繁体的写法替换，在 OpenCC 和台湾异体字之后套用。
# - 以 = 开头：对转换结果再做一次繁体到繁体的替换，用来修 OpenCC 在很多词组里都一样的误转（比如几十个带「克制」的词都转成「剋制」）。
# - 转换前后字数必须一样，不一样的会被忽略。
# 用字：台湾日常写「台」，不写「臺」
